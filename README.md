# video2md

Chrome の **Live Caption（自動字幕起こし）** に出た字幕を読み取って、Markdown ファイルに保存する macOS 用ツールです。
Moodle などの講義動画を再生するだけで、文字起こしが `.md` になります。API キーも料金も不要で、音声は端末の外に出ません。

```md
# Live Caption 文字起こし

## 文字起こし

- [00:12] 今日は固有値について説明します。
- [00:31] まず行列Aが与えられたとき…
```

## 仕組み
Chrome の Live Caption は字幕を独立したウィンドウに表示します。macOS のアクセシビリティ API でそのウィンドウの文字を 1 秒ごとに読み、新しく出た分だけを追記します（単語間の空白の除去、訂正に備えた確定待ち、重複排除つき）。

## 使い方

### A. クローンして使う（CLI）
```bash
git clone https://github.com/oldsheeep3/video2md.git
cd video2md
./start.sh
```
- 初回は Swift でビルドします（Command Line Tools が必要: `xcode-select --install`）。
- 起動時に **アクセシビリティ権限** を確認します。未許可ならダイアログが出るので、使っているターミナルアプリ（Terminal / iTerm など）をオンにしてください。許可されるまで待機します。
- 起動したら Chrome で動画を再生します。Ctrl-C で終了すると保存されます。
- 保存先は `~/Documents/Moodle文字起こし/live_<日時>.md` です。`./start.sh 出力.md` で指定もできます。

### B. メニューバーアプリ（.app / .dmg）
```bash
./build_app.sh   # dist/Video2MD.app と dist/Video2MD.dmg ができる
```
- 起動するとメニューバーに 📝 が出ます。メニューから「記録を開始 / 停止して保存」を切り替えます（記録中は 🔴）。
- 初回起動時にアクセシビリティの許可ダイアログが出ます。許可すると自動で使えるようになります。
- 記録を始めて 15 秒たっても字幕ウィンドウが見つからないと、Live Caption がオフの可能性を案内して設定ページを開けます。

#### 配布するときの注意
- ad-hoc 署名（Developer ID なし）なので、他の Mac で初めて開くときは「開発元を確認できません」と出ます。右クリック →「開く」で開けます。警告なしで配るには、Apple Developer Program での署名と公証が必要です。
- ad-hoc 署名のアプリは、ビルドし直すとアクセシビリティの許可が外れることがあります。その場合は設定で付け直してください。

## 事前準備
Chrome の **設定 → ユーザー補助 → 自動字幕起こし** をオンにします（日本語の動画なら言語も日本語に）。
Live Caption の設定は macOS の保護で読み取れないため、アプリからオン/オフを直接は判定できません。字幕ウィンドウが出ないときに、上記のとおり案内します。

## 制約
- 字幕の精度は Live Caption に依存します（聞き間違いはそのまま入ります）。
- タイムスタンプは記録を始めてからの経過時間です（動画内の位置ではありません）。
- 動画を一時停止している間は字幕が出ないので、何も追記されません。
- macOS 13 以降、Google Chrome が対象です。
